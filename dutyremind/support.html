Installation & Setup Guide

Follow these instructions to install the add-on, configure your Google Sheet roster, and sync events to Google Calendar.

1. How to Install

  • Open the Google Spreadsheet where you maintain your duty roster or shift charts.
  • Navigate to the top menu and click: Extensions → Add-ons → Get add-ons.
  • Search for DutyRemind in the Google Workspace Marketplace.
  • Click the Install button (or use this direct Marketplace installer link).
  • Grant the required Google Calendar and Spreadsheets permissions.
  • Refresh your active sheet tab.
  • In the menu, click: Extensions → DutyRemind → Configure to open the setup sidebar.

2. Configure Spreadsheet Mapping

In the Setup tab of the sidebar, map the layout of your sheet roster using the 1-based indexing values:

  • Target Sheet Name: The name of the tab containing your roster data.
  • Header Rows: Number of rows at the top containing metadata (default is 5).
  • Header Columns: Fixed columns on the left before the dates begin (default is 2).
  • Date Row: The row containing dates (default is row 2).
  • Slot Row: The row containing shift identifiers like FN/AN (default is row 4).
  • Email Column: The column containing employee/customer email addresses (default is column 1).

3. Configure Shift Slots & Overrides

Open the Manage Slots tab to define durations for shift code labels:

  • Default Slots: For example, define FN (Forenoon) from 09:15 to 12:30, and AN (Afternoon) from 13:15 to 16:30.
  • Day Overrides: Expand a slot card to customize times for specific days (e.g. override AN on Fridays to run from 13:45 to 17:00).

4. Set Notifications & Sync

Configure your event titles, notifications, and run the sync:

  • Calendar Tab: Customize the event title (e.g., "Team Duty") and description. Add native calendar notifications (email or popup alerts, e.g., 30 minutes before shifts). Press Save All Settings.
  • Synchronize: Click: Extensions → DutyRemind → Sync Calendars. An execution dialog will open showing detailed additions, updates, or deletions.

5. Synchronization Logic Rules

DutyRemind follows these strict rules when executing synchronization:

Case-Insensitive Shift Code Matching: Roster codes in the cells are matched case-insensitively with slot configuration IDs (e.g. fn matches slot FN).

Assigning Attendees: Row values are parsed column-by-column. An 'X' or 'x' indicates the employee/customer should be scheduled; any other value or blank cell removes them from the event.

Filter Past Dates: Sync ignores columns with roster dates prior to today in the calendar's timezone, preserving past logs.

Empty Slots Auto-Delete: If no guest is assigned to a shift, DutyRemind automatically deletes the corresponding calendar event to avoid cluttering.
